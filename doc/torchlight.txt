1. INTRODUCTION                                   *torchlight-introduction*

Torchlight is a dark colorscheme for Neovim. It takes its palette from the
painting "Fishing by Torchlight in Kai Province" by Katsushika Hokusai.

The palette holds few blue hues. This keeps the colorscheme easy on the eyes
at night.

==============================================================================
2. REQUIREMENTS                                   *torchlight-requirements*

- Neovim 0.8.0 or later.
- A terminal with true color support.

Torchlight sets 'termguicolors' when it loads.

==============================================================================
3. SETUP                                                 *torchlight-setup*

                                                       *torchlight.setup()*
Install the plugin, then call `setup()`. With lazy.nvim: >lua

    {
      "skylarmb/torchlight.nvim",
      lazy = false,
      priority = 1000,
      opts = {
        contrast = "medium",
      },
    }
<
Load the colorscheme by hand with either form: >lua

    require("torchlight").setup({ contrast = "medium" })
<
>vim
    colorscheme torchlight
<
`:colorscheme torchlight` keeps the options from an earlier `setup()` call.
Call `setup()` first when you want a contrast level other than the default.

Options ~

                                                        *torchlight-options*
contrast                            string    default: "hard"
    The background contrast level. See |torchlight-contrast|.

==============================================================================
4. CONTRAST                                           *torchlight-contrast*

The `contrast` option sets how dark the background is. It accepts four
values. The foreground colors do not change.

    Value       Background      Description ~
    "medium"    #1E1D1D         The lightest supported background.
    "hard"      #131312         The default.
    "stark"     #0d0d0d         The darkest background, close to black.
    "soft"      #252424         Deprecated. See below.

Example: >lua

    require("torchlight").setup({ contrast = "stark" })
<
                                                     *torchlight-soft*
The "soft" value is deprecated. It still works, and it will keep working.
It is no longer maintained. New colors and fixes do not reach it. Use
"medium" for the closest supported background.

The ports in `extras` follow the same rule. Each soft port file carries a
note at the top.
==============================================================================
5. PLUGIN SUPPORT                               *torchlight-plugin-support*

Torchlight sets highlight groups for these plugins:

    avante.nvim         gitsigns.nvim       nvim-cmp
    dashboard-nvim      lazy.nvim           nvim-dap-ui
    neo-tree.nvim       lualine.nvim        nvim-notify
    neogit              nvim-tree           nvim-treesitter
    snacks.nvim         telescope.nvim

Plugins that are absent from this list still work. They use the default
highlight groups.

==============================================================================
6. TERMINAL COLORS                             *torchlight-terminal-colors*

Torchlight sets `g:terminal_color_0` through `g:terminal_color_15`. The
built-in terminal uses the palette of the colorscheme.

==============================================================================
7. PORTS                                                 *torchlight-ports*

The `extras` folder in the repository holds the palette for other tools.
Ports cover Alacritty, Ghostty, WezTerm, and Zed. Each terminal port has one
file per contrast level.
